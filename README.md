# basilisk-lagrangian-tracer
MPI-parallel Lagrangian tracer particles for Basilisk: RK3 advection, neighbour-only migration on the multigrid, bit-identical results at any rank count. Works with Navier-Stokes, stream and multilayer (hydro, nh) solvers on multigrid and quadtree/octree grids, with spherical coordinates, surface tracers, MPI-IO output and restarts.
